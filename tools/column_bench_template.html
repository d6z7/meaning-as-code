MAC · column bench

Every key of the column block

Required, default and legal values are read from column_specification.md's own key table. Plane, outcome classes, status and reader come from column_effects.yaml. Neither file restates the other, and a key in one and not the other fails the gate.

The consequence matrix

Every key against every effect it can have. The two dashed columns are not gradings of an answer — a load refusal and a red gate happen before a question exists. The other four are mac.outcome_class, the axis the whole estate already grades in. Read a column to learn what can possibly refuse; read a row to learn what one key can do.

Which ruling, and what the measurement cannot tell you

Three counts decide which ruling a column pair is a candidate for — and on two of the four branches the measurement gets you to the door and no further. Drag the dials, or load a constellation measured on contoso.
