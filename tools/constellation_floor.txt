# gen_key_reference CONSTELLATION FLOOR — how many keys may still state no constellation.
#
# 177 -> 161. 177 was the count the moment the field existed and nothing used it; 161 is the count
# after the column block and the three column vocabularies were written, measured 2026-10-04.
#
# A RATCHET, AND IT MOVES ONE WAY. Lower it by WRITING a constellation, never by raising it to make
# a run green. The gate prints its own slack, because a floor above the measurement is headroom
# rather than a ratchet — the leak gate's own floor file records a count that fell to 4 while the
# declaration still said 146, which is 142 findings of permission nobody granted.
#
# WHY THIS IS A FLOOR AND NOT A REJECT. A key with no stated constellation is a real debt and there
# are 161 of them; a hard reject would have been red on its first run and stayed red, which is how a
# gate becomes something people pass a flag to. What may NOT happen is a NEW key arriving without
# one — that is what this number catches, on the day it happens.
161

# 161 -> 465, RE-BASED 2026-10-05 because the DENOMINATOR MOVED, not the debt. 161 was measured
# when gen_key_reference walked ConceptFile and nothing else. It now walks twelve file shapes
# across both planes — project, relation, lookup, transform, ontology, edges, rules and the five
# governance declarations — so the old number was a count over one file type being compared with a
# count over twelve. ConceptFile's own share FELL over the same period (161 -> 153, eight written),
# which is the evidence that this is arithmetic and not regression.
#
# IT IS STILL A ONE-WAY RATCHET. A new key that states no constellation pushes this up and fails.
# The honest next step is a floor PER ROOT, so a thirteenth shape can never again hide inside one
# number the way the three data-plane roots hid inside 161 for a day.
465

# 465 -> 464, 2026-10-08. ONE key gained a constellation, and it did so as a SIDE EFFECT of the
# fifth-revision column surface rather than by anybody writing a paragraph: `grounding.sources[]`
# became `grounding.source`, `roles` became `offers`, and `identity` retired, so the key population
# itself changed shape. The pages were regenerated in the same pass (45 rejects over 120 pages:
# 19 uncovered keys, 8 orphan pages, 7 missing pages, 6 stale pages — every one of them the manual
# lagging that surface change).
#
# LOWERED BECAUSE THE GATE ASKED. Its verdict line read "constellation floor 465, measured 464 —
# 1 of SLACK, lower the floor", which is the mechanism working: a floor above the measurement is
# headroom, and headroom is how this estate's leak floor stood at 146 while the real count was 4.
# One of slack is small enough to be worth nothing and exactly big enough to teach the habit.
