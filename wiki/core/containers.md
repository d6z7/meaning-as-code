### WHAT FORCED IT

<!-- q 2026-09-12/022-reading-a-container-is-not-answering-from-it#WHAT FORCED IT -->
> The task was "open an ontology and inspect it, like a file". `open_container` already existed and
> already took a `require_trust` floor whose docstring says "a host that ANSWERS should pass

> collapsed that into one `ok=False`.

## had two served bundles declare which connector they use, proving the declaration is free today by an A/B whose only differences were wall clock

### WHAT FORCED IT

<!-- q 2026-09-13/064-declare-the-connector-with-zero-schema-change#WHAT FORCED IT -->
> STAGE A2 of the connector architecture. A bundle must NAME a connector for any of the rest to be
> possible, and the cheapest possible version of that step is the one that changes nothing else.

### EVIDENCE

<!-- q 2026-09-13/064-declare-the-connector-with-zero-schema-change#EVIDENCE -->

> `runtime.connector: mac.connector.athena`. Nothing else changes.
>
> > This is free today because `ProjectFile.runtime` is literally `{"type": "object"}` in the grammar —
> > no properties, no required, no additionalProperties — so the declaration validates immediately and
> > can sit UNREAD for the whole soak period. It is the bundle's only forward commitment, and it is a
> > namespaced identifier rather than a shape, so it survives whichever way the open rulings go.
